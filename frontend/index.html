Qwen MemoryAgent

Track 1 · Global AI Hackathon

What is this?

MemoryAgent is a persistent memory layer for AI chat. Most chatbots forget everything the moment a session ends — this one doesn't. Every fact you share gets scored for importance by Qwen, stored with an embedding for semantic search, and recalled automatically in future sessions — even if you close the tab, come back tomorrow, and never mention it again.

Try this in under a minute
  1. Register a new account below (any username/password works — e.g. judge1) — this gives you a clean, isolated identity with no prior history.
  2. Tell it a few facts about yourself in one message, e.g. "My name is Alex, I'm a backend engineer, and I'm allergic to peanuts."
  3. Click New Session (top bar) — this clears the visible chat, simulating a brand-new conversation.
  4. Ask: "What do you know about me?" — it will recall what you said, even with zero visible chat history. That recall is the whole point.
What's in the side panel

Every stored memory shows a colored importance bar (Qwen's own 0–1 score) and an expiry date. Low-importance facts (small talk, filler) expire in 24 hours; mid-importance in 7 days; high-importance facts (names, goals, deadlines) are kept permanently.

Things worth testing
  • Contradictions: tell it one preference, then later tell it the opposite — watch it decide whether to update the old memory or keep both as independent facts.
  • 🧹 Smart Forget: triggers a review of any memories past their expiry — Qwen makes a final keep/delete call on each rather than blind deletion.
  • Duplicate facts: say the exact same thing twice — it should recognize the repeat and skip storing it again.
Notes for evaluation

Memory is isolated per account — registering with a different username creates a completely separate identity with no access to anyone else's data. Passwords are hashed (bcrypt) and every request is verified with a JWT, not a client-supplied identity string. Source, architecture diagrams, and deployment details are in the GitHub repo.
